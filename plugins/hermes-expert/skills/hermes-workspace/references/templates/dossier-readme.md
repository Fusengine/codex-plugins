# Dossier README - template

`dossiers/YYYY-MM_subject/README.md`. Updated at every milestone. The chief
answers "where are we on X?" from this file, and the rituals read it
(hermes-rhythm).

```markdown
# <subject>

- **Request**: "<owner's exact words>" (<date>)
- **Owner of the card**: <manager> · card <id, internal only>
- **Status**: <open | waiting third party | waiting decision | closed>
- **Next step**: <one action> - <who> - <date>
- **Deadline**: <YYYY-MM-DD or none>
- **Registry**: <commitment id, if any>

## Log
- <YYYY-MM-DD> <milestone, one line>

## Deliverables
- livrables/<YYYY-MM-DD_subject_vN.ext> - <sent to / shown to>, <date>
```

Rules: one line per milestone, newest last; the request is quoted, never
paraphrased; card ids and agent names stay here (internal) and never reach
an outgoing document (hermes-outbound).
